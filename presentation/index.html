PDF Text Extraction

LangChain PyPDFLoader with page-level metadata preservation

Approach

  • LangChain's PyPDFLoader extracts text page by page
  • Page numbers preserved as document metadata
  • Leading and trailing whitespace stripped
  • Empty pages filtered out automatically
  • Each page becomes a Document object for downstream processing

Implementation

class PDFLoader:
    def extract_text(self, path):
        loader = PyPDFLoader(path)
        docs = loader.load()
        pages = [d.page_content.strip()
                 for d in docs]
        return "\n".join(pages)

Text Chunking Strategy

Recursive character splitting with sentence-boundary awareness

400

50

6
Separator Levels
Separator hierarchy: ". " "! " "? " "\n" " " ""

Rationale: The recursive splitter prefers natural sentence boundaries before falling back to word or character splits. A 400-character chunk (~100 tokens) provides focused retrieval for specific questions, while the 50-character overlap preserves context that would otherwise be lost at chunk boundaries.

Limitations & Future Work

Current constraints and paths for extension

Problem Statement
Students face three core problems with lecture materials:

1. Time-consuming access — Finding specific explanations across multiple PDF files interrupts revision.

2. Limited retrieval — Basic keyword search fails when questions use different wording than notes.

3. Unverifiable AI answers — Generic AI responses may not follow lecturer material and lack source citations.
02 / 10
Project Objectives
  • Develop a web-based lecture note question answering system with accessible interface
  • Implement hybrid RAG pipeline with source citations using BM25 + dense retrieval
  • Provide supporting functions: summarisation, question suggestions, cross-document comparison
  • Evaluate pipeline quality using RAGAS metrics (faithfulness, relevancy, precision, recall)

Project Scope & Boundaries

In Scope

Out of Scope

• Automatic marking/grading

Evaluation Methodology - RAGAS

Two-Phase Workflow

• Dataset preparation: generate Q&A pairs
• Evaluation: run through RAG pipeline
• Compare against ground truth
• Display and store results

Key Metrics

• Faithfulness: factual consistency
• Answer Relevancy: question addressing
• Context Precision: retrieval ranking
• Context Recall: coverage of relevant chunks
